## Description

This is a simple one-page website for a fictional university called **Bright Future University**. It is built with HTML, CSS and JavaScript.

The page includes:

- A header with the university name and slogan
- A navigation bar that scrolls to each section
- **Home** section with a welcome message, campus image and a button that shows a welcome alert
- **About** section with a short introduction and library image
- **Departments** section with a list of departments
- **Programs** section with a table of programs, durations and degrees
- **Admission** section with an inquiry form (name, email, contact number, gender, program)
- A footer with copyright text

1. Download or clone the repository:
   ```

   ```
2. Open the project folder.
3. Double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox).

No installation is needed.
